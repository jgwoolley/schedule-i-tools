Schedule I Tools

A pawn shop calculator and save viewer for Schedule I. Drop a zip of your save folder to fill in the day and see your stats. Everything is read in your browser; nothing is uploaded.

Expects a .zip of a SaveGame_N folder (or just its Time.json to set the day)
Where do I find my save?
Windows (Steam)%USERPROFILE%\AppData\LocalLow\TVGS\Schedule I\Saves\
Steam Deck / Linux (Proton)~/.local/share/Steam/steamapps/compatdata/3164500/pfx/drive_c/users/steamuser/AppData/LocalLow/TVGS/Schedule I/Saves/
Linux (Flatpak Steam)~/.var/app/com.valvesoftware.Steam/.local/share/Steam/steamapps/compatdata/3164500/pfx/drive_c/users/steamuser/AppData/LocalLow/TVGS/Schedule I/Saves/
macOS (CrossOver)~/Library/Application Support/CrossOver/Bottles/<bottle>/drive_c/users/crossover/AppData/LocalLow/TVGS/Schedule I/Saves/
macOS (Whisky)~/Library/Containers/com.isaacmarovitz.Whisky/Bottles/<bottle>/drive_c/users/crossover/AppData/LocalLow/TVGS/Schedule I/Saves/

Inside is a folder named after your Steam ID, with one SaveGame_N folder per save slot. Zip the slot's folder (on Windows: right-click it and choose "Compress to ZIP file"), then drop the zip here.

Schedule I only has a Windows build, so on Linux, Steam Deck and macOS the save sits inside the compatibility layer's emulated Windows drive. 3164500 is the game's Steam app ID. If the game is installed on an SD card or a second drive, look for steamapps/compatdata/3164500 in that drive's Steam library instead. On macOS, replace <bottle> with the name of the bottle the game is installed in.

How the pawn price works

Read from the game's code (PawnShopInterface.GetItemValue). Not checked against offers in the running game.

Valuestore price × resell multiplier × quantity × daily multiplier
Opening offerthe total value of the items in the five pawn slots, rounded
Daily multipliera hash of the second letter of the item's name plus the elapsed day number, mapped to 0.5–2.0 and passed through a curve. The letter has almost no effect, so every item gets the same multiplier each day.
Day patterndays 10–99 depend only on the tens digit (ten days in a row are identical); days 100–999 depend on the hundreds and ones digits (a ten-day cycle)
Roundingnone up to $25, then to the nearest $5 up to $100, $10 up to $1,000, $50 up to $10,000, $100 up to $100,000, $500 up to $1,000,000

Schedule I has no published formulas or save format. The numbers here come from:

  • Il2CppDumper and GNU objdump, used to read the pawn shop code out of the game's IL2CPP build.
  • UnityPy, used to read item prices, store listings and the pawn shop's price curve from the game's asset files.
  • A save file from game version 0.4.6f13, used to work out the save layout.

See README.md in this project for how the pawn formula was tracked down and how to redo it after a game update. This is a fan-made tool and is not affiliated with TVGS.
